# DTF Cherry links

Public link page for DTF Cherry, hosted free on GitHub Pages.

Live site: https://loganflip.github.io/dtf-cherry-links/

## Change a link

Open `index.html`. Each button is one `<a class="link">`. Change the words inside `<strong>` and the address in `href`.

## Change colors

Open `styles.css`. The brand colors are the variables at the top: cherry, blush, paper, and ink.

## Change pictures

Replace the files in `assets/` and keep the same names:

- `logo.png` — the mark at the top
- `products.jpg` — the photo beside the links
- `favicon.png` — the browser icon

## Publish an edit

Commit and push to `main`. GitHub Pages updates the live site from that branch. On GitHub you can also use the pencil on `index.html` and commit straight to `main`.
